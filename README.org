Implemented in v1.7. Files touched: =popup.html=, =popup.js=, =options.html=,
=options.js=, =content-script.js=, =manifest.json=.

1. *Source language* — new dropdown in both the popup and the full options
   page, stored as =srcLang= in =chrome.storage.sync= (default =auto=). The
   content script now builds the Google Translate URL with the user-chosen
   =sl=, via two helpers =gtansUrl()= / =ftranUrl()= (replaced the hardcoded
   =config.gtans= / =config.ftran= prefixes).

2. *Export to .org* — every captured subtitle is buffered in-memory as
   ={ original, translation, ts }=. New *Export captured subtitles (.org)*
   button in the popup sends an =exportOrg= message; the content script
   builds an org-mode document and triggers a download via a Blob URL +
   programmatic =<a download>=. Format matches the requested shape for
   org-anki — each original subtitle is a level-1 heading (=* ...=), the
   translation is the body. A leading literal =*= in subtitle text is
   escaped to =\*= so it doesn't break the heading structure.

3. *Header with Netflix meta* — the export starts with =#+TITLE=, =#+DATE=,
   =#+URL=, =#+SOURCE_LANG=, =#+TARGET_LANG=, =#+SUBTITLE_COUNT=. Title is
   best-effort: tries =[data-uia="video-title"]=, =.video-title h4=,
   =.video-title=, =.ellipsize-text=, =.title-info-title=,
   =.title-info h1=, =h1.title= in order, then falls back to
   =document.title= with the trailing =" | Netflix"= stripped. Netflix
   often hides the title in a transient overlay that disappears after a
   few seconds, so the most reliable moment to click *Export* is right
   after the player tooltip is visible.

Caveats:
- The buffer lives in the page's content-script context. Reloading the
  Netflix tab clears it; export before reloading.
- =chrome.storage.sync= is used, so srcLang/lang sync across signed-in
  browser profiles. Reload the Netflix tab after changing language for
  the new value to take effect on subsequent subtitles (already-fetched
  translations are cached for that session).
